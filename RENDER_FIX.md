# Исправление ошибки деплоя на Render.com

## Проблема
```
npm error path /opt/render/project/src/package.json
npm error errno -2
npm error enoent Could not read package.json
```

## Решение

### Вариант 1: Настройка через веб-интерфейс Render

1. Зайдите в настройки вашего Web Service на Render
2. Найдите поле **"Root Directory"**
3. Убедитесь, что оно **пустое** или содержит **`.`** (точка)
4. **НЕ** указывайте `src/` или другие поддиректории
5. Сохраните изменения и перезапустите деплой

### Вариант 2: Использование render.yaml

Файл `render.yaml` уже обновлен с правильными настройками:
- `rootDir: .` - указывает на корень проекта

Убедитесь, что файл `render.yaml` находится в **корне** вашего репозитория (на том же уровне, что и `package.json`).

### Вариант 3: Ручная настройка команд

Если `render.yaml` не работает, настройте вручную:

1. **Root Directory**: оставьте пустым или укажите `.`
2. **Build Command**: 
   ```bash
   npm run install-all && npm run build
   ```
3. **Start Command**: 
   ```bash
   npm start
   ```
4. **Environment Variables**:
   - `NODE_ENV` = `production`
   - `PORT` - Render установит автоматически

### Проверка структуры проекта

Убедитесь, что структура проекта выглядит так:
```
.
├── package.json          ← должен быть в корне
├── render.yaml           ← должен быть в корне
├── server/
│   └── index.js
├── client/
│   ├── package.json
│   └── src/
└── ...
```

### Если проблема сохраняется

1. Удалите существующий сервис на Render
2. Создайте новый Web Service
3. При подключении репозитория убедитесь, что:
   - Root Directory пустое или `.`
   - Выбран правильный branch (обычно `main` или `master`)
4. Используйте настройки из `render.yaml` или настройте вручную

### Альтернатива: Использование Railway.app

Если Render продолжает вызывать проблемы, попробуйте Railway.app:
- Автоматически определяет структуру проекта
- Использует `railway.json` (уже настроен)
- Более простая настройка
