# Discord Clone - Голосовой и текстовый чат

Аналог Discord с поддержкой текстового и голосового чата в реальном времени.

## Возможности

- ✅ Текстовый чат в реальном времени
- ✅ Голосовой чат через WebRTC
- ✅ Система серверов и каналов
- ✅ Множественные пользователи
- ✅ Современный интерфейс в стиле Discord
- ✅ Русское радио (8 популярных станций)

## Технологии

### Backend
- Node.js + Express
- Socket.io для real-time коммуникации
- SQLite для хранения данных

### Frontend
- React
- Socket.io-client
- WebRTC API для голосового чата

## Установка

1. Установите зависимости для всего проекта:
```bash
npm run install-all
```

Или отдельно:
```bash
# Backend зависимости
npm install

# Frontend зависимости
cd client
npm install
```

## Запуск

### Режим разработки (одновременно backend и frontend):
```bash
npm run dev
```

### Или отдельно:

Backend сервер (порт 5000):
```bash
npm run server
```

Frontend приложение (порт 3000):
```bash
npm run client
```

## Использование

### Локальное использование:
1. Откройте браузер и перейдите на `http://localhost:3000`
2. Введите ваше имя пользователя для входа
3. Выберите сервер и канал
4. Для текстового чата - просто начните писать сообщения
5. Для голосового чата - нажмите "Присоединиться к голосовому каналу" и разрешите доступ к микрофону

### Подключение друзей:

**После деплоя на хостинг (Render.com, Railway и т.д.):**
1. Получите URL вашего приложения (например: `https://discord-clone.onrender.com`)
2. Отправьте эту ссылку другу
3. Друг открывает ссылку в браузере, вводит имя и начинает общаться!

**Для локального использования (без хостинга):**
1. Узнайте ваш IP адрес (выполните `ipconfig` в командной строке)
2. Откройте порты 5000 и 3000 в файрволе Windows
3. Запустите сервер: `npm run dev`
4. Сообщите другу ваш IP адрес

**Для вашего друга (локально):**
1. Откройте браузер и перейдите на `http://ВАШ_IP:3000`
2. Если появится окно настройки - введите адрес сервера: `http://ВАШ_IP:5000`
3. Введите имя и начните общаться!

## Примечания

- Для голосового чата требуется HTTPS в продакшене (WebRTC требует безопасное соединение)
- В разработке можно использовать HTTP, но некоторые браузеры могут блокировать доступ к микрофону
- База данных SQLite создается автоматически при первом запуске
- По умолчанию создается тестовый сервер с текстовым и голосовым каналами

## Деплой на хостинг

### Быстрый деплой на Render.com:

1. Загрузите код в GitHub
2. Зайдите на [render.com](https://render.com)
3. Создайте новый Web Service
4. Подключите GitHub репозиторий
5. Настройки:
   - Build Command: `npm run install-all && npm run build`
   - Start Command: `npm start`
6. Дождитесь деплоя и получите URL!

### Другие варианты:
- **Railway.app** - использует `railway.json`
- **Fly.io** - использует `Dockerfile`
- **Render.com** - использует `render.yaml`
