# Инструкция по настройке сети для подключения друзей

## 📋 Быстрая инструкция

### Для вас (хост сервера):

1. **Узнайте ваш IP адрес в локальной сети:**
   - Windows: Откройте командную строку и выполните `ipconfig`
   - Найдите "IPv4-адрес" (например: 192.168.1.100)

2. **Откройте порты в файрволе Windows:**
   ```powershell
   # Откройте PowerShell от имени администратора и выполните:
   New-NetFirewallRule -DisplayName "Discord Clone Server" -Direction Inbound -LocalPort 5000 -Protocol TCP -Action Allow
   New-NetFirewallRule -DisplayName "Discord Clone Client" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
   ```

3. **Запустите сервер:**
   ```bash
   npm run dev
   ```

4. **Сообщите другу ваш IP адрес** (например: `192.168.1.100`)

### Для вашего друга:

1. **Откройте браузер** и перейдите на: `http://ВАШ_IP:3000`
   Например: `http://192.168.1.100:3000`

2. **Если появится окно настройки сервера:**
   - Введите адрес: `http://ВАШ_IP:5000`
   - Например: `http://192.168.1.100:5000`

3. **Введите имя пользователя** и начните общаться!

## 🔧 Подробная настройка

### Вариант 1: Локальная сеть (Wi-Fi/кабель)

Если вы и ваш друг в одной сети (один роутер):

1. **Узнайте IP адрес сервера:**
   ```bash
   # Windows PowerShell
   ipconfig
   
   # Или в терминале после запуска сервера будет показан IP
   ```

2. **Откройте порты в файрволе:**
   - Порт 5000 (backend сервер)
   - Порт 3000 (frontend приложение)

3. **Друг подключается по:** `http://ВАШ_IP:3000`

### Вариант 2: Через интернет

Для подключения через интернет нужен:

1. **Внешний IP адрес** (узнайте на https://whatismyipaddress.com/)
2. **Проброс портов на роутере:**
   - Порт 5000 → IP вашего компьютера:5000
   - Порт 3000 → IP вашего компьютера:3000
3. **Друг подключается по:** `http://ВАШ_ВНЕШНИЙ_IP:3000`

⚠️ **Внимание:** Для работы через интернет может потребоваться настройка роутера (port forwarding).

### Вариант 3: Использование Radmin VPN (Рекомендуется! 🌟)

**Radmin VPN** создает виртуальную локальную сеть - все участники получают IP-адреса в одной подсети, как будто вы в одной локальной сети. Это самый простой способ для подключения друзей!

#### Преимущества:
- ✅ Не нужно настраивать роутер
- ✅ Работает через интернет
- ✅ Простая настройка
- ✅ Бесплатно
- ✅ Безопасно (зашифрованное соединение)

#### Инструкция:

**Для вас (хост сервера):**

1. **Установите Radmin VPN:**
   - Скачайте с официального сайта: https://www.radmin-vpn.com/
   - Установите и запустите

2. **Создайте сеть:**
   - Нажмите "Создать сеть"
   - Придумайте имя сети и пароль
   - Запишите эти данные (понадобятся другу)

3. **Узнайте ваш IP в Radmin VPN:**
   - В интерфейсе Radmin VPN будет показан ваш IP (обычно начинается с `26.x.x.x`)
   - Или выполните в PowerShell:
     ```powershell
     ipconfig | findstr "26."
     ```
   - Найдите адаптер "Radmin VPN" и его IPv4-адрес

4. **Запустите сервер:**
   ```bash
   npm run dev
   ```
   - Сервер автоматически определит IP адрес Radmin VPN
   - В консоли будет показан адрес для подключения

5. **Откройте порты в файрволе Windows:**
   ```powershell
   # Откройте PowerShell от имени администратора
   New-NetFirewallRule -DisplayName "Discord Clone Server" -Direction Inbound -LocalPort 5000 -Protocol TCP -Action Allow
   New-NetFirewallRule -DisplayName "Discord Clone Client" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
   ```

**Для вашего друга:**

1. **Установите Radmin VPN:**
   - Скачайте с официального сайта: https://www.radmin-vpn.com/
   - Установите и запустите

2. **Подключитесь к вашей сети:**
   - Нажмите "Присоединиться к сети"
   - Введите имя сети и пароль (которые вы дали)
   - Подождите подключения (статус должен стать "Подключено")

3. **Откройте браузер и перейдите:**
   - `http://ВАШ_IP_В_RADMIN:3000`
   - Например: `http://26.123.45.67:3000`
   - IP адрес вы должны сообщить другу

4. **Если появится окно настройки сервера:**
   - Введите адрес: `http://ВАШ_IP_В_RADMIN:5000`
   - Например: `http://26.123.45.67:5000`

5. **Введите имя пользователя** и начните общаться!

#### Как узнать IP адрес в Radmin VPN:

**Способ 1: Через интерфейс Radmin VPN**
- В главном окне программы будет показан ваш IP адрес

**Способ 2: Через командную строку**
```powershell
# Windows PowerShell
ipconfig | findstr "26."
```
Найдите строку с IPv4-адресом для адаптера "Radmin VPN"

**Способ 3: Через API сервера**
- После запуска сервера откройте в браузере:
- `http://localhost:5000/api/server-info`
- В ответе будет список всех IP адресов, включая Radmin VPN

#### ⚠️ Важно:
- Оба компьютера должны быть подключены к одной сети Radmin VPN
- Убедитесь, что файрвол разрешает подключения на портах 3000 и 5000
- IP адрес в Radmin VPN обычно начинается с `26.x.x.x`

### Вариант 4: Использование ngrok (для тестирования)

1. **Установите ngrok:** https://ngrok.com/
2. **Запустите туннель:**
   ```bash
   ngrok http 5000
   ```
3. **Скопируйте URL** (например: `https://abc123.ngrok.io`)
4. **Друг подключается по этому URL**

## 🛡️ Настройка файрвола Windows

### Через графический интерфейс:

1. Откройте "Брандмауэр Защитника Windows"
2. Нажмите "Дополнительные параметры"
3. Выберите "Правила для входящих подключений" → "Создать правило"
4. Выберите "Порт" → TCP → Укажите порты: 5000, 3000
5. Разрешите подключение

### Через PowerShell (от администратора):

```powershell
# Разрешить порт 5000
New-NetFirewallRule -DisplayName "Discord Clone Server" -Direction Inbound -LocalPort 5000 -Protocol TCP -Action Allow

# Разрешить порт 3000
New-NetFirewallRule -DisplayName "Discord Clone Client" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
```

## ⚠️ Решение проблем

### Проблема: "Не удается подключиться"

1. **Проверьте файрвол** - порты должны быть открыты
2. **Проверьте IP адрес** - убедитесь, что используете правильный IP
3. **Проверьте, что сервер запущен** - на сервере должно быть видно сообщение о запуске
4. **Проверьте сеть** - вы должны быть в одной сети (для локального подключения)

### Проблема: Голосовой чат не работает

1. **Разрешите доступ к микрофону** в браузере
2. **Проверьте настройки WebRTC** - некоторые браузеры требуют HTTPS для микрофона
3. **Для работы через интернет** может потребоваться TURN сервер (настройка сложнее)

### Проблема: "CORS ошибка"

- Убедитесь, что сервер запущен с обновленным кодом (CORS настроен на "*")
