# Инструкция по деплою на бесплатные хостинги

## 🚀 Варианты бесплатных хостингов

- ✅ HTTPS из коробки

- ✅ Встроенный редактор
- ⚠️ Ограничения на бесплатном плане

## 📦 Деплой на Render.com (Пошаговая инструкция)

### Шаг 1: Подготовка репозитория

1. Создайте аккаунт на [GitHub](https://github.com)
2. Создайте новый репозиторий
3. Загрузите код:
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/ВАШ_USERNAME/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

### Шаг 2: Деплой на Render

1. Зайдите на [render.com](https://render.com) и зарегистрируйтесь
2. Нажмите **"New +"** → **"Web Service"**
3. Подключите ваш GitHub репозиторий
4. **ВАЖНО**: Убедитесь, что **Root Directory** установлен в `.` (точка) или оставлен пустым
5. Настройки:
   - **Name**: `discord-clone` (или любое другое)
   - **Environment**: `Node`
   - **Root Directory**: `.` (точка - корень проекта)
   - **Build Command**: `npm run install-all && npm run build`
   - **Start Command**: `npm start`
   - **Plan**: `Free`
6. Добавьте переменные окружения:
   - `NODE_ENV` = `production`
   - `PORT` Render установит автоматически (не нужно указывать вручную)
7. Нажмите **"Create Web Service"**

**Примечание**: Если используете `render.yaml`, Render автоматически применит настройки из файла. Убедитесь, что файл находится в корне репозитория.

### Шаг 3: Ожидание деплоя

- Render автоматически соберет и задеплоит приложение
- Дождитесь завершения (обычно 5-10 минут)
- После деплоя вы получите URL вида: `https://discord-clone.onrender.com`

### Шаг 4: Использование

1. Откройте полученный URL в браузере
2. Введите имя пользователя
3. Начните общаться!

## 🚂 Деплой на Railway.app

### Шаг 1: Подготовка

1. Зарегистрируйтесь на [railway.app](https://railway.app)
2. Подключите GitHub аккаунт

### Шаг 2: Создание проекта

1. Нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. Выберите ваш репозиторий

### Шаг 3: Настройка

Railway автоматически определит настройки из `railway.json`:
- Build команда: `npm run install-all && npm run build`
- Start команда: `npm start`

### Шаг 4: Переменные окружения

Railway автоматически установит `PORT`. Убедитесь, что `NODE_ENV=production`

### Шаг 5: Получение URL

Railway автоматически создаст домен вида: `discord-clone.up.railway.app`

## ✈️ Деплой на Fly.io

### Шаг 1: Установка CLI

```bash
# Windows (PowerShell)
iwr https://fly.io/install.ps1 -useb | iex

# Или через winget
winget install flyctl
```

### Шаг 2: Логин

```bash
flyctl auth login
```

### Шаг 3: Инициализация

```bash
flyctl launch
```

Следуйте инструкциям. Fly.io создаст `fly.toml` файл.

### Шаг 4: Деплой

```bash
flyctl deploy
```

## 🔧 Локальная сборка для тестирования

Перед деплоем можно протестировать продакшен сборку локально:

```bash
# Установите зависимости
npm run install-all

# Соберите React приложение
npm run build

# Запустите продакшен сервер
npm start
# или на Windows:
npm run start:win
```

Откройте `http://localhost:5000` в браузере.

## 🔒 Важные замечания

### HTTPS
- Все перечисленные хостинги предоставляют HTTPS автоматически
- Это важно для работы WebRTC (голосовой чат)

### База данных
- SQLite файл будет храниться в файловой системе
- При перезапуске контейнера данные могут потеряться (на бесплатном плане)
- Для постоянного хранения рассмотрите использование внешней БД (PostgreSQL)

### WebRTC через интернет
- Для работы голосового чата через интернет может потребоваться TURN сервер
- В локальной сети STUN серверов Google обычно достаточно

### Ограничения бесплатных планов
- **Render**: приложение "засыпает" после 15 минут бездействия
- **Railway**: ограниченный кредит ($5/месяц)
- **Fly.io**: требует карту для бесплатного плана

## 🐛 Решение проблем

### Проблема: "Cannot find module"
Убедитесь, что в `package.json` есть скрипт `install-all`:
```json
"install-all": "npm install && cd client && npm install"
```

### Проблема: Порт не определен
Убедитесь, что используете `process.env.PORT` в коде (уже настроено).

### Проблема: Статические файлы не загружаются
Проверьте, что:
1. React приложение собрано (`npm run build`)
2. В `server/index.js` настроена раздача статики (уже настроено)

### Проблема: Socket.io не работает
Убедитесь, что CORS настроен правильно (уже настроено на "*").
